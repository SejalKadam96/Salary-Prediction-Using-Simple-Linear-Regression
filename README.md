# Salary Prediction Using Simple Linear Regression

## 📌 Project Overview

This project uses **Simple Linear Regression**, a Machine Learning algorithm, to predict a person's salary based on their years of experience.

The model learns the relationship between **Years of Experience** and **Salary** using historical data.

---

## 🎯 Objective

The main objective of this project is to build a Simple Linear Regression model that predicts salary based on years of experience.

- **Input Feature:** YearsExperience
- **Target Variable:** Salary

---

## 📊 Dataset

The dataset contains information about:

- Years of Experience
- Salary

The dataset is used to train and test the Machine Learning model.

---

## 🔄 Project Workflow

1. Import required libraries
2. Load the salary dataset
3. Explore and understand the dataset
4. Check for missing values
5. Visualize the relationship between experience and salary
6. Select input and target variables
7. Split the data into training and testing sets
8. Train the Simple Linear Regression model
9. Make salary predictions
10. Visualize the regression line
11. Evaluate the model performance

---

## 🤖 Machine Learning Model

The model used in this project is:

**Simple Linear Regression**

Simple Linear Regression is used because there is one input variable, **YearsExperience**, and one output variable, **Salary**.

The model finds the relationship between years of experience and salary and uses it to make predictions.

---

## 📈 Model Evaluation

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

These metrics help evaluate how accurately the model predicts salary.
